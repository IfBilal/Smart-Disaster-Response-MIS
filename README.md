# Smart Disaster Response Management Information System

A comprehensive MIS built for emergency and disaster response, featuring role-based dashboards, inventory management, incident tracking, and financial tracking.

## Repository
GitHub Repo: [https://github.com/IfBilal/Smart-Disaster-Response-MIS](https://github.com/IfBilal/Smart-Disaster-Response-MIS)

## System Roles
- Administrator
- Emergency Operator
- Field Officer
- Warehouse Manager
- Finance Officer

## Tech Stack
- Frontend: Next.js / React, Tailwind CSS
- Backend API: Next.js App Router (Node.js)
- Database: Microsoft SQL Server (Transact-SQL)
- Data Modeling: EERD (Diagrams.net)

## Project Structure
- `/database`: Contains SQL schema, triggers, stored procedures, and views.
- `/descriptions`: EERD Diagrams (`.drawio`).
- `/docs`: Technical documentation and PDFs.
- `/src`: Frontend and Backend application code.
